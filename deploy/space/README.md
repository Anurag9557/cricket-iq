# CricketIQ — live win-probability replay

Ball-by-ball T20 win probability, a live match-replay engine, and a verified LLM analyst
that will not state a number it did not compute.

This Space serves a **precomputed, read-only demo** over a curated set of matches: pick a
match, press Play to watch the win-probability curve build ball by ball, and click any
key moment for the verified AI commentary and the model's SHAP drivers.

Full project, source, and write-up: **https://github.com/Anurag9557/cricket-iq**
